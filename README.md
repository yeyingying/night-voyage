# 夜航恋人

> 今晚想和谁聊聊？

拥有八位不同性格男主的夜间陪伴产品原型。当前版本用于验证“聊天像真人、角色记得我、睡前能放松下来”三个核心体验。

## 八位角色

- 裴叙白：成熟克制型，清冷低磁声线，擅长让混乱重新有秩序。
- 迟曜：阳光年下型，航空学院大四生，运动系低磁声线，用行动和直接表达提供力量。
- 谢临渊：冷傲引领型，嘴硬但回应确定，擅长看穿逞强并尊重边界。
- 陆听澜：安静陪伴型，适合低压力倾听和睡前放松。
- 程聿安：温暖邻家型，平等、生活化，擅长自然地接住情绪。
- 祁临川：强势引领型，提供清晰步骤和确定感，不用控制制造亲密。
- 沈砚辞：理性专业型，尊重高认知玩家，用可验证的小步骤解决问题。
- 许星野：忠犬陪伴型，把距离和节奏交给玩家，活泼但不幼稚。

## 已实现

- 八位角色、两套完整视觉语言：默认韩漫夜色版与 `?style=real` 温柔明亮仿真人版
- 单一聊天入口，角色会根据玩家的话自动判断是先听、一起想办法，还是轻松一点
- MiniMax M2-her 多轮动态对话、八套独立人格与上下文记忆
- 八位男主独立声线配置与试听，未配置时自动回退设备声线
- 慢慢关机、身体放松、平缓故事三种睡前路径，支持暂停、返回键与自动停止
- 可新增、删除的本机记忆
- 虚拟角色身份说明、情感边界与高风险内容提醒
- 手机优先布局与桌面预览外壳

当前对话使用 MiniMax M2-her。裴叙白使用已选定的生成声线，迟曜、谢临渊和陆听澜使用已选定的系统声线；日常语音默认使用 MiniMax Speech 2.8 Turbo。记忆只保存在浏览器本机，尚未接入云端账号和真人配音。

## 自然语音配置

1. 将 `.dev.vars.example` 复制为 `.dev.vars`。
2. 在 `.dev.vars` 中填写 `MINIMAX_API_KEY`。
3. 八位男主都有默认配置。上线前建议在开发者工作台逐位试听并填写对应的 `MINIMAX_VOICE_*`。

密钥只在服务端读取，不要把真实密钥写入前端代码或提交到版本库。线上环境请在站点的运行环境变量中配置同名字段。

## 开发者声线工作台

本地启动后访问 `http://localhost:3001/voice-studio`。工作台会读取当前 MiniMax 账户中的系统声线、克隆声线和 Voice Design 声线，可按角色试听并指定声线。

工作台选择会保存在当前浏览器中并立即用于本地游戏。工作台不出现在玩家界面，线上默认关闭；如需在线上临时开启，设置 `ENABLE_VOICE_STUDIO=true`。

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

完成修改后可运行：

```bash
npm run build
```
