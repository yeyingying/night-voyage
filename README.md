# 夜航恋人

> 每一次晚安，都是与你重逢。

拥有四位不同关系类型男主的夜间情绪伴侣产品原型。当前版本用于验证“情绪被接住、角色记得我、能够自然结束一天”三个核心体验。

## 四位角色

- 裴叙白：克制守护型，低沉慢语速，擅长让混乱重新有秩序。
- 迟曜：热烈年下型，清亮快语速，用行动和直接表达提供力量。
- 晏无咎：危险掌控型，低哑长停顿，擅长看穿逞强并尊重边界。
- 陆听澜：温柔疗愈型，温润留白感，适合倾听和睡前放松。

## 已实现

- 四人角色选择、独立视觉主题与本机选择记忆
- “抱抱我 / 陪我理清 / 逗我开心”三种陪伴模式
- 四套独立性格对话、情境回应和压力安慰方式
- 四种设备声线参数与独立声线试听
- 四套 12 分钟熄屏哄睡台词、呼吸节奏、语音与自动停止
- 可新增、删除的本机记忆
- 虚拟角色身份说明、情感边界与高风险内容提醒
- 手机优先布局与桌面预览外壳

当前语音使用设备内置中文朗读能力，并通过语速、音高和可用中文声线区分角色；记忆只保存在浏览器本机。尚未接入正式对话模型、云端账号和真人配音。

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

完成修改后可运行：

```bash
npm run build
```
