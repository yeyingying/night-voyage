# 夜航恋人

> 每一次晚安，都是与你重逢。

以裴叙白为第一位角色的夜间情绪伴侣产品原型。当前版本用于验证“情绪被接住、角色记得我、能够自然结束一天”三个核心体验。

## 已实现

- 今晚主页与裴叙白角色主视觉
- “抱抱我 / 陪我理清 / 逗我开心”三种陪伴模式
- 可输入的情绪对话与情境化回应
- 12 分钟熄屏哄睡流程、呼吸节奏、语音与自动停止
- 可新增、删除的本机记忆
- 虚拟角色身份说明、情感边界与高风险内容提醒
- 手机优先布局与桌面预览外壳

当前语音使用设备内置中文朗读能力，记忆只保存在浏览器本机；尚未接入正式对话模型、云端账号和真人配音。

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

完成修改后可运行：

```bash
npm run build
```
