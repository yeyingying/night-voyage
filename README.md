# 夜航恋人

> 每一次晚安，都是与你重逢。

拥有四位不同关系类型男主的夜间情绪伴侣产品原型。当前版本用于验证“情绪被接住、角色记得我、能够自然结束一天”三个核心体验。

## 四位角色

- 裴叙白：克制守护型，低沉慢语速，擅长让混乱重新有秩序。
- 迟曜：阳光年下型，航空学院大四生，清爽快语速，用行动和直接表达提供力量。
- 晏无咎：危险掌控型，低哑长停顿，擅长看穿逞强并尊重边界。
- 陆听澜：温柔疗愈型，温润留白感，适合倾听和睡前放松。

## 已实现

- 四人角色选择、独立视觉主题与本机选择记忆
- “抱抱我 / 陪我理清 / 逗我开心”三种陪伴模式
- MiniMax M2-her 多轮动态对话、四套独立人格与上下文记忆
- 四种 MiniMax 中文男声与独立声线试听，未配置时自动回退设备声线
- 四套 12 分钟熄屏哄睡台词、呼吸节奏、语音与自动停止
- 可新增、删除的本机记忆
- 虚拟角色身份说明、情感边界与高风险内容提醒
- 手机优先布局与桌面预览外壳

当前对话使用 MiniMax M2-her，语音使用 MiniMax Speech 2.8：日常对话使用 Turbo，哄睡使用 HD；记忆只保存在浏览器本机。尚未接入云端账号和真人配音。

## 自然语音配置

1. 将 `.dev.vars.example` 复制为 `.dev.vars`。
2. 在 `.dev.vars` 中填写 `MINIMAX_API_KEY`。
3. 可选填写四个 `MINIMAX_VOICE_*`，绑定经授权复刻或 Voice Design 生成的专属音色；留空会使用四种不同的系统男声。

密钥只在服务端读取，不要把真实密钥写入前端代码或提交到版本库。线上环境请在站点的运行环境变量中配置同名字段。

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

完成修改后可运行：

```bash
npm run build
```
