# 可复制给任意生图模型的提示词包

## 使用方法

每次只生成一张图，并同时上传：

1. 该角色的真人主脸锚点；
2. 如果生成韩漫版，再上传该角色的韩漫锚点；
3. 将下方“角色身份块 + 场景块 + 风格块”拼接成完整提示词。

不要只写“同一个男人”。必须重复身份、发型、标志服装和禁止项。

## 真人通用风格块

```text
用途：乙女游戏角色场景图，真实摄影。
图像必须像由专业相机在真实空间中拍摄，而不是游戏CG或插画。成年亚洲男性，真实自然的皮肤纹理、毛孔、细小不对称、真实发丝与布料；面部比例正常健康，不瘦长、不纸片V脸。人物英俊但可信，保留生活感。使用自然人像镜头透视，人物脸部清楚，夜景也必须有柔和暖面光。整体温柔明亮，背景有氛围但不能黑成一片。
保持参考图中的同一人物身份、头发轮廓、年龄、标志服装与气质，只改变指定的场景、动作和情绪。
禁止：CG、3D render、游戏建模、动漫、韩漫、插画、蜡像皮、磨皮滤镜、过度化妆、超长脸、尖锐V脸、巨大眼睛、完美对称、过度锐化、明星复刻、文字、水印。
画幅：竖版9:16，眼睛位于画面上方约35%，下方保留聊天UI安全区。
```

## 韩漫通用风格块

```text
用途：乙女游戏韩漫版角色场景图。
输入图1是真人场景与构图参考，输入图2是该角色的韩漫身份参考。把图1逐项翻译为统一的高品质现代韩漫插画：人物身份、年龄、发型轮廓、服装层次、眼镜或饰品、姿势、表情、镜头、光线方向和背景布局都与图1对应；脸与图2是同一角色。
风格为精致现代韩漫线稿、自然人体比例、克制细腻的五官、高级但不过度光滑的上色、柔和明亮的夜色、清晰面光。四季与时间可变化，但全项目线条粗细、肤色逻辑、阴影边缘和高光方式保持一致。
禁止：改脸、改年龄、改发型、摘掉标志眼镜、增加奇幻服装、Q版、日漫大眼、厚涂油画、3D、真人摄影、文字、水印。
画幅：与图1相同的竖版9:16，保留UI安全区。
```

## P0 场景块

### S01 初见主视觉

```text
他刚刚注意到镜头外的玩家，停下手里的事并抬眼。胸部以上中近景，眼神与镜头建立直接联系，表情符合他的性格，不摆拍，不夸张微笑。背景是能说明其职业的真实空间。第一眼必须同时呈现“帅、可接近、与其他角色不同”。
```

### S02 日常随手拍

```text
像他在自己的真实日程中随手分享的一张照片，不是影楼写真。他正在白天上班、上课或处理自己的事情，动作自然，画面允许轻微不完美，环境有可信的同事/校园/工作痕迹但不出现抢镜人物。表情松弛，像发来一句“刚忙完，你呢？”
```

### S03 开心/逗你

```text
他被玩家逗笑，或正准备反过来开一个小玩笑。笑容必须符合角色：迟曜和许星野更明显，裴叙白和陆听澜只露出克制的笑，谢临渊是有点得逞的轻笑。眼神活，身体略向镜头靠近，不做广告式标准笑容。
```

### S04 吃醋/小脾气

```text
他听见玩家提到另一个暧昧对象，出现真实但克制的不高兴。不是暴怒，不恐吓；表现为眼神停顿、嘴角收起、轻微侧头或短暂避开视线。仍然英俊、有边界、有可和好的空间。画面传达“他有自己的情绪，不是永远服从”。
```

### S05 靠近安慰

```text
深夜，玩家情绪很差。他坐到更近的位置，身体微微前倾，目光专注，像正在认真听完一句很难说出口的话。手部自然地放在安全可见的位置，可递来一杯温水或轻轻示意坐近，但不强行触碰。温暖面光，背景安静，安全感优先。
```

### S06 睡前近距离

```text
成年人之间克制而清晰的暧昧睡前场景。镜头距离更近，像视频通话结束前他把声音放低；衣着完整，不裸露，不做色情姿势。眼神停留稍久，表情含一点逗弄或舍不得结束的意味。床边灯或沙发暖灯，皮肤与发丝真实，画面温柔而有张力，不低俗。
```

## P1 场景块

- S07 工作状态：专注处理职业事务，不能只是换背景摆拍。
- S08 兴趣/社交：与朋友、同事或个人爱好有关，但配角不露脸或弱化。
- S09 疲惫破绽：他也会累、会沉默，不向玩家索取情绪劳动。
- S10 生气后和好：仍有余气，但愿意靠近谈清楚。
- S11 约会纪念：一段关系独有的地点或物件，不能是通用烛光晚餐。
- S12 高关系度暧昧：衣着完整、成年人、双方自愿的亲密距离与语言张力，不做露骨性行为。

## 韩漫转换专用附加句

```text
本张不是重新设计角色，而是对已验收真人成图的逐项风格翻译。除媒介从真实摄影变为统一韩漫插画外，不改变任何身份与叙事信息。
```
